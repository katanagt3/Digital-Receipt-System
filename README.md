# 🏢 Digital Receipt System

A Python-based Command Line Interface (CLI) tool designed to automate manual billing processes and generate digital receipts. 

## 🎯 Project Objective
This project demonstrates the practical application of **Digitalisierungsmanagement** (Digitalization Management). It bridges the gap between traditional economic processes and modern IT solutions by transforming a manual, paper-based task into a streamlined, automated digital workflow. 

## ✨ Features
*   **Automated Calculations:** Instantly computes total costs based on price and quantity.
*   **Digital Output:** Generates beautifully formatted `.txt` receipts automatically.
*   **Error Handling:** Robust input validation to ensure data integrity.
*   **No External Dependencies:** Built entirely with standard Python libraries.
